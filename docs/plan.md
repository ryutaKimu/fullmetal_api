# 作りたいもの
鋼の錬金術師のナレーションの台詞を返すAPI

# なぜ作る？
後続で作るナレーション暗唱サービス、チャットbotの基盤となるAPIが必要

# 利用シーン
1. サービス利用者(主に開発者である私)がスタートボタンを押すと、「話数: XX話 タイトル: XX」と表示される。それに合わせて、利用者は音声認識でセリフを話す。回答合わせでセリフを返す。「セリフは非表示で、答えを見るボタンで表示」「一致箇所は緑、不一致は赤」
2. 開発者が毎朝9:00にランダムでナレーションを流す。返すセリフはランダム。

# 機能価値
セリフ暗唱がスムーズに行える（現状は都度検索している）。APIがあることで、検索する手間が省ける
かつ、botや他で作ろうとしているサービスにも転用ができる。

# 最小単位
1. ランダム取得

# 拡張案
1. 前半、中盤、後半で分類が可能(区分分けは要検討)
2. 複数件のランダム取得（重複なし）
3. 英訳versionを保持。それを元に言語フラグで返すセリフやタイトルを切り替えられる
